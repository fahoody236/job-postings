Bilingual Marketing Website — Saudi Accounting SaaS

Project: A public marketing website (not the app itself) for a Saudi cloud accounting/finance SaaS platform targeting Saudi SMEs. The product already exists; this is the site that explains it, shows pricing, and drives trial sign-ups.
Scope: ~6 core pages (Home, Features, Pricing, About, Contact, Legal), plus optional add-ons (blog, case studies, ZATCA explainer, help docs) to be quoted separately.
Must-haves:
Full bilingual Arabic/English site with true RTL layout for Arabic — not a translated skin
Persistent language switcher, hreflang SEO, proper Arabic web font
Mobile-first, fast (<3s load), accessible
Client must be able to edit page copy without a developer
Pricing page with comparison table, SAR pricing, FAQ
Analytics + Search Console setup, contact form with spam protection
Platform: Open to recommendation (Webflow, Framer, or Next.js/Astro static site) — must justify choice, especially re: content editing.
Client will provide: logo/brand assets (or quote to create), screenshots, final pricing, legal/about copy, sign-up URL — some items arriving mid-project, flagged clearly in the brief.
Looking for in proposals:
Recommended platform + reasoning
Approach to bilingual RTL (with past examples if available)
Timeline with milestones
Itemized cost (site, copywriting, brand work, nice-to-haves, ongoing hosting)
Relevant prior work — especially bilingual Arabic/English sites
Full brief attached with complete requirements, page-by-page content, and success criteria.
